# Mini Programs
A collection of programs which are too small to have their own repository. Each progrram is designed to do one small task.

Currently avalaible programs:
###  quadratic_eqn_roots.c
Find roots of a quadratic equation. Takes input in the form of ax^2+bx+c = 0. Also finds complex roots.

### ceasar_cipher_tool.c
My program which ciphers or deciphers text using ceasar cipher

### intTo_ASCII.c
A simple program which accepts a integer in rag=nge of 0-127 and prints the equivalent ASCII character

### multiFileCompiling
Small sample which demonstrates compiling more than 1 file. A function is used from another file in this example.
